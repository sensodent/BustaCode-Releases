# Accessibility

BustaCode builds on Code - OSS and includes custom BustaAI, BustaAgents, Graph and DevOps interfaces. These views may have accessibility issues even when upstream editor features are accessible.

We aim to improve keyboard operation, contrast, focus behavior, zoom support and screen-reader usability, but **do not currently claim audited WCAG conformance**.

To report a barrier, use the [Bug report form](https://github.com/sensodent/BustaCode-Releases/issues/new/choose), prefix the title with `[Accessibility]`, and describe the workflow, assistive technology (if relevant), expected vs. actual result, version and steps to reproduce.

Please do not share sensitive medical or personal information.
