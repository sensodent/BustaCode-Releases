# BustaCode Support

**BustaCode's public repository is for downloads, documentation and feedback.**

| Need | Where |
| --- | --- |
| Install or update | [Latest release](https://github.com/sensodent/BustaCode-Releases/releases/latest) |
| Common questions | [FAQ](FAQ.md) |
| Product bug | [Bug report](https://github.com/sensodent/BustaCode-Releases/issues/new/choose) |
| Improvement idea | [Feature request](https://github.com/sensodent/BustaCode-Releases/issues/new/choose) |
| How-to question | [Question / Help](https://github.com/sensodent/BustaCode-Releases/issues/new/choose) |
| Accessibility barrier | [Accessibility information](ACCESSIBILITY.md) |
| Sensitive security concern | [Security policy](SECURITY.md) — never report publicly |

Please search before posting, reproduce the issue on the latest version where possible and remove secrets or private information from attachments.

GitHub Discussions may become the main place for open-ended community conversations once enabled.

**Note:** Cursor, Codex and other third-party providers operate their own accounts, subscriptions, authentication and usage limits. BustaCode maintainers cannot manage those services for you.
