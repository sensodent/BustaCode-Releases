# Frequently Asked Questions

### Is BustaCode free?

Yes, the application installer is free to download. AI provider subscriptions, credits, APIs and usage limits are independent and may involve separate charges.

### Is BustaCode open source?

It is based on MIT-licensed Code - OSS, but **BustaCode's complete source is currently private**. This public repository contains releases and community documentation. See [LICENSE](LICENSE).

### BustaCode vs. BustaAgents?

They are two modes of the **same application**. The IDE includes editor, debugger and terminal. BustaAgents hides the traditional editor layout so you can focus on agent conversations, tasks and changes, then switch back without losing your session.

### Which operating system is supported?

The published installer is for **Windows x64**.

### Which AI providers are available?

BustaAI integrates with Codex, the official Cursor CLI over ACP, and the OpenAI API. Model availability, account requirements and capabilities depend on the provider.

### Can I install VS Code extensions?

BustaCode uses [Open VSX](https://open-vsx.org) and can install supported VSIX files. It does **not** use the Microsoft Visual Studio Marketplace, so proprietary Microsoft-only extensions may be unavailable.

### Does BustaCode send my code to its servers?

Project context is maintained locally by BustaCode, but the relevant context and instructions are sent to the **selected AI provider** when you make a request. Your provider's policies also apply.

### How do I update?

Use BustaCode's built-in update system or download from the [official releases page](https://github.com/sensodent/BustaCode-Releases/releases). Installers and manifests are verified by the application's update workflow.

### Where do I ask for help?

See [SUPPORT.md](SUPPORT.md), the [issue templates](https://github.com/sensodent/BustaCode-Releases/issues/new/choose), and [SECURITY.md](SECURITY.md) for private vulnerability reporting.
