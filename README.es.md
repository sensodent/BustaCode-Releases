## Descubre BustaCode

**BustaCode** es un entorno de desarrollo de escritorio basado en [Code - OSS](https://github.com/microsoft/vscode). Combina un editor completo con **BustaAI**, una experiencia unificada para trabajar con agentes de programación.

Programa directamente en el editor o céntrate en tus agentes. **Sin tener que alternar entre múltiples aplicaciones y ventanas.**

## Dos modos. El mismo BustaAI.

### BustaCode — IDE completo

Editor, terminal, depurador, extensiones, herramientas Git y BustaAI en el mismo espacio de trabajo.

![Captura del IDE BustaCode](assets/busta-code-ide.png)

### BustaAgents — Modo centrado en agentes

Oculta el IDE tradicional y deja que BustaAI ocupe el espacio principal. Conversa con tus agentes, supervisa las tareas y revisa los cambios. Vuelve al editor cuando quieras **sin cambiar de aplicación ni perder la conversación activa**.

![Captura de BustaAgents](assets/busta-agents.png)

> **BustaAgents no es otra aplicación.** Es otra vista de la misma ventana, los mismos proyectos y las mismas conversaciones de BustaCode.

## ¿Qué incluye?

| Funcionalidad | Qué ofrece |
| --- | --- |
| **BustaAI** | Chat unificado, modos **Ask / Plan / Agent** y una interfaz común para los proveedores compatibles. |
| **Proveedores de IA** | **Cursor** mediante su CLI oficial y ACP, **Codex** mediante app-server e integración de la **API de OpenAI**. Cada proveedor utiliza su propio motor de ejecución. |
| **Memoria del proyecto** | Contexto estructurado y editable con objetivos, decisiones, instrucciones, archivos relevantes y estado Git. |
| **Conversaciones paralelas** | Varios chats de agentes en pestañas con indicadores de estado e historial independiente. |
| **Git y worktrees** | Diffs, cambios, ramas, historial, worktrees y flujos de pull requests. |
| **MCP y herramientas** | Integraciones MCP por proyecto a través de un gateway local con controles de acceso. |
| **Docker y DevOps** | Contenedores, logs e inspección de servidores Linux por SSH: CPU, memoria, servicios y puertos. |
| **Busta Graph** | Explora relaciones, dependencias, rutas API, modelos, DAO y tablas de bases de datos. |
| **Arquitectura** | Diagramas de arquitectura generados con ayuda de agentes y Archify. |
| **Extensiones** | Compatibilidad con extensiones de Code - OSS mediante [Open VSX](https://open-vsx.org/) e instalación manual de VSIX. |

## Empieza a utilizarlo

1. **[Descarga el último instalador para Windows](https://github.com/sensodent/BustaCode-Releases/releases/latest).**
2. Instala BustaCode y abre un proyecto.
3. Abre **BustaAI** y conecta un proveedor compatible. Alterna entre **BustaCode** y **BustaAgents** desde la aplicación.

BustaCode es **gratuito**. Las cuentas, claves API, suscripciones, límites de uso y posibles costes de los proveedores son **independientes**. Las integraciones de Cursor y Codex utilizan sus herramientas y sistemas oficiales de autenticación.

## Privacidad, extensiones y actualizaciones

- El contexto del proyecto y el estado local de BustaAI se gestionan en tu equipo. El contexto relevante se envía al **proveedor de IA elegido** al realizar una petición.
- La ejecución de herramientas y los permisos dependen del motor seleccionado; BustaAI muestra solicitudes de autorización y actividad cuando el proveedor lo permite.
- El catálogo de extensiones es **Open VSX**, **no el Visual Studio Marketplace de Microsoft**. Algunas extensiones propietarias pueden no estar disponibles.
- El actualizador verifica los manifiestos y la integridad de los instaladores mediante firmas criptográficas y checksums.
